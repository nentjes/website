# nentjes-v2

Nieuwe meertalige website voor Roel Nentjes: presentaties, AI- en robotverkenningen, architectuur, roadmaps en realisatie.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Controleren

```bash
npm run lint
npm test
```

De huidige website op nentjes.nl wordt pas vervangen nadat deze versie inhoudelijk en visueel is goedgekeurd.
